Work added in this capsule includes effective birth-leg construction,
auxiliary source-marginal response features with offline learned coefficients,
current-support/query scheduling and final-layer allocation, bounded recursive
multiplication plans, exact contraction and nonlinear-program rewrites,
immutable coefficient caching, and lifetime-based buffer reuse. The selected
release combines the r8 implementation with the q31k4 statistical additions
and the October 16 public-network response refit.
These additions extend and optimize the original method; organizer review
determines whether they satisfy the substantial-original-contribution criterion.

The supplied coefficients.npz contains numeric coefficient data, not executable
code or per-instance predictions. The latest response
coefficients were fitted on all 100 public mini networks, with grouped
cross-validation used during selection. Its reported mini100 score is
in-sample for this refit, not an independent private evaluation. Earlier
versions used smaller public training panels. There is no seed/name
lookup of predictions in the estimator. The inherited calibration constants
and original method remain credited to their original author.

LLM assistance was used extensively for code development, optimization and
analysis in this capsule. Measurements, limitations, and rejected variants are
retained in the accompanying local evidence, which is not part of this upload.
This note is provenance disclosure, not a final algorithmic-contribution write-up.

Release r6 prepares the original capacity geometries during setup, reusing
only owned scratch preparation graphs. It uses public fnp.zeros for zero
initialization, omits unused basis views, and skips full-size identity slices
when a prepared view already has the exact required dimensions. All numerical
operations remain metered. Coefficients, recurrence, ranks and support gates
are unchanged. Cache invalidation precedes stage storage growth.

Release r8 retains the configured confined rank as an exact capacity
dimension instead of rounding that dimension up with variable support sizes.
All logical product dimensions, arithmetic, coefficients and model settings
are unchanged. Other capacity dimensions keep their original rounding.

2026-10-21 time-aware recursion depth (Claude). Before each hidden layer the
estimator reads the standard-library monotonic clock and selects how deep the
existing exact Strassen-Winograd plans recurse: this package's native policy
(W24j arithmetic with the exact 2304 level-7 template and setup trim, argon_2 and
Codex; small rank-320 tight layouts, Codex) when the elapsed time leaves room;
else every rank-320 product at level 5 (the cand_w21a_v2 policy, argon_2); else
additionally level 7 disabled. A dense metered matmul is kept only as an
emergency fallback when even the shallowest tier could not finish inside the
wall-clock cap. The level-5 fallback capacity geometries are compiled at setup
from shapes only. Model state, ranks, supports and coefficients are identical in
every tier; only the billed FLOP count, floating-point summation order and wall
time differ, so billed FLOPs can vary slightly between runs. The clock drives
control flow only; all arithmetic remains public flopscope operations.
